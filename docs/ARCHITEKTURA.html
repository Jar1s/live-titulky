LIVE TITULKY — architektúra a dátové toky

semestrálny projekt · Python 3.12 · whisper.cpp (ANE) + MLX kinit-turbo-sk · WebSocket UI · 3 vymeniteľné ASR enginy

Lokálny režim

  • • draft: whisper base, CoreML na Apple Neural Engine (~0.4 s)
  • • final: kinit-turbo-sk (MLX, Metal GPU) — slovenský model
  • • LocalAgreement-2: slovo sa potvrdí, keď sa 2 behy zhodnú
  • • presné časy slov → titulky sedia na slovo
  • • audio nikdy neopustí Mac (privátne)

Cloud režim

  • • posiela sa výhradne PCM16 16 kHz audio (base64 chunky)
  • • OpenAI: text bez časov slov → titulky približné (korekcia −1.8 s + ručný posun)
  • • ElevenLabs Scribe v2: slová s časmi → presné titulky
  • • prepínanie enginov za behu v UI, bez reštartu

Testy

  • • 21/21 testov prechádza (pytest, ~68 s)
  • • e2e video pipeline s mock Eleven serverom
  • • fixtures: 9 WAV scenárov (ticho, šum, 2 rečníci, tempo…)
  • • benchmark: WER na referenčných nahrávkach (docs/BENCHMARK.md)
